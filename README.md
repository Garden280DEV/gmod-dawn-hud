# HL:Dawn Damage Indicators

This is a Garry's Mod addon which aims to recreate the HUD for damage numbers from Half-Life: Dawn servers. It however does not try to achieve a 1:1 recreation.

[Subscribe on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2929922284)

## Features

- *Full multiplayer* and singleplayer support.
- *Customization* of basically any property, including the ability to turn the addon off on client and/or server.
- *Hitsounds*, both for light damage and heavy damage.
